Thanks for using Crash Doctor!

OUR OWN BUGS, FIXED

• On some setups Crash Doctor itself crashed the game whenever a party's roster changed: the game picked up the mod's build for 1.2 instead of the one for 1.3 and later. The two builds now have different names, and the loader refuses a wrong one instead of running it.

• The "destroyed parties back on the map" save repair never worked once, and on every reload it reported a repair that did not happen. Rewritten: it now checks the map after the load has finished.

• report.txt was not written when the game runs on the .NET Core runtime. Fixed.

WHAT'S NEW

• Mods tab: a dependency written against a mod's old name (Europe 1700 add-ons asking for EoE1700) is no longer reported as missing when the renamed mod is installed. Characters borrowing equipment sets no mod defines are named before the campaign starts.

• Linux / Steam Deck (Proton): checks that change Windows settings are no longer offered.

• Tales from the Age of Men: Crash Doctor saw Harmony as off and its live guards stood idle. Fixed.

• Save cleaning: a new "also remove glitched parties" box — off by default, and it never touches your own party.

• The exported report.txt hides your Windows user name and PC name.

• The shader-cache cards no longer delete files shipped with the game or with mods.

NEW CRASH GUARDS

• A map crash 20–30 seconds after every load: a clan with no leader on the daily tick.

• A siege deployment crash: a mod asked an empty formation for its nearest enemy.

• A crash opening a settlement menu that asks for places the settlement does not have.

• A town or village crash: a resident missing from the list of the place they walk through.

• A TOR battle crash on killing a unit whose troop has no culture.

• A new-campaign crash: a character borrows an equipment set that does not exist.

• The ownerless-party guard now also covers War Sails' daily ship repair.
