Thanks for using Crash Doctor!

OUR OWN BUG, FIXED

• On Bannerlord 1.2.10 the mod itself broke the wage calculation: a guard installed at the main menu ran a piece of game code too early, the game cached the failure, and every party's wage read zero until restart — while the mod counted the fallout as 94,332 "prevented crashes". No guard is installed that early any more, and a failure like that is now reported once, in honest words.

• The encounter-menu guard no longer loops: one log had 3,223 firings in two minutes, each counted as a rescue. A repeat is now detected and reported once.

WHAT'S NEW

• report.txt carries an enhanced stack: the position inside each method, the nearest call there and the owners of every patch on it. No third-party crash reporter needed any more.

• Native crashes are read from the dump: the faulting library decides the verdict — graphics driver, injected overlay, sound engine, or a mod's own native DLL. The mod used to delete the dump before reading it.

• Crash folders match the mod's own record in any time zone (folder names are UTC), and the module list names mod ids, not folders.

• The Mods tab scans in the background with progress, and remembers the result until a file changes. A module listed twice in the load order, a manifest the game cannot read and a translation placed above its mod are reported before launch.

• The shader-cache button touches only the generated cache — never a file shipped by the game or a mod.

• A fix waiting for a game session shows as "Deferred", not "Not needed". Long texts scroll instead of shrinking. The Prevented tab folds repeats into one row and follows your language.

NEW CRASH GUARDS

• A day-change crash from an item whose category belongs to a previous campaign in the same game session. Restart the game before loading a save.

• A crash on the first reinforcement wave when a mod adds a team after the battle started.

• A battle crash while drawing the banner icon over soldiers sharing one banner.

• A crash when a merchant sends out a caravan — a game regression since the naval update.

• A map crash every tick from a settlement with no owner clan — one added to the game after your save was made.

• A map crash seconds after every load: a hero executed with no executioner on record (1.5+).

• A childbirth crash on a parent with no face data — now repaired instead of patched around.

• A crash at siege start from a roster whose headcount says men while its list is empty.

• A crash from a banner texture landing on armour already destroyed with its soldier.
