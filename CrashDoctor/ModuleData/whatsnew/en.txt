Thanks for using Crash Doctor!

WHAT'S NEW

• Crash guard for placing troops at the start of a battle on some scenes. A battle that used to run fine could suddenly crash on entry. On by default on the "Crash fixes" tab.

• Crash guard for deploying, recruiting and the Party screen with custom-troop mods (e.g. My Little Warband). The cause is a non-weapon item in a troop's weapon slot. On by default.

• Crash guard for loading a save made at the "at the gate" town menu. If the encounter didn't restore on load the whole save wouldn't open; now the player is returned to the map and the save opens. On by default.

• A load crash caused by the FDS ShaderCache mod is now explained. During its shader rebuild that mod blacklists an XML the game needs, so objects vanish and the game crashes loading a campaign (most often on setups with The Old Realms). Crash Doctor now recognises this crash, and a button on the System tune-up tab clears the blacklist in one click.
